## Контрольне запитання

**Питання:** Як визначити, чи є дата останнім днем місяця в pandas?

**Відповідь:** У бібліотеці `pandas` для стовпця з типом даних `datetime64` (отриманого через `parse_dates` або `pd.to_datetime()`) використовується вбудована властивість **`dt.is_month_end`**. Вона повертає логічний `Series` (`True`, якщо дата є останнім днем місяця, і `False` — в іншому випадку), який зручно застосовувати безпосередньо для фільтрації `DataFrame`:

```python
month_end_rows = df[df["date"].dt.is_month_end]
```
